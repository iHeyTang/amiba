# @amiba/dsh-bundle-amiba-core

The Electron-independent Amiba product layer for DeepSeek Harness.

It composes durable memory, file attachments, messaging, skills, MCP,
commands, schedules, usage, and capability catalog services. It can be
layered over both `dsh-headless` and `dsh-web-app`; no row in this bundle may
require Electron or a browser UI.
