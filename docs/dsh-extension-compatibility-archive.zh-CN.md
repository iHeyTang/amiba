## 有确切原因的限制

| 能力 | 已确认原因 | 本阶段处理 |
| --- | --- | --- |
| 一次性子会话继续发送或停止 | rc.2 公共接口拒绝 | 不能通过当前公共接口完整对齐，需上游变更或另行设计 |
| 可续聊子会话向模型发送图片 | rc.2 公共接口不支持；图片命令是另一条能力 | 保留已有功能，不宣称模型图片已支持 |
| 冷嵌套子会话恢复 | 要求直接父 Agent 驻留，缺少公共的无消息冷恢复操作 | 当前条件下无法完整对齐 |
| Host 队列编辑图片和子会话目标 | rc.2 仅支持文本并拒绝子会话目标 | 保留原生图片/子会话队列，不能直接全量替换 |
| 官方子会话普通文件上传 | 固定对照版本明确拒绝，错误为 SUBAGENT_FILE_UNSUPPORTED | 归为上游限制，保留 Amiba 原生子会话附件能力 |
| 插件依赖私有 DOM、Electron API 或丢失的源位置 | 私有结构无通用契约；纯浏览器缺少宿主 API；丢失的 Markdown 映射无法凭空恢复 | 只能按具体插件和宿主评估专用适配，不承诺通用完整支持 |

重启后恢复整个撤销/重做栈不计入缺口：已核对的官方版本也不持久化完整编辑历史。草稿、队列和附件的恢复仍是上表中的待办。
