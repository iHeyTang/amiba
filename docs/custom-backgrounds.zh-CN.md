# 主界面动态背景

背景是 Amiba UI shell 的持久化外观功能。默认关闭，保留原有布局；启用后由一个根级背景层播放图片或静音循环视频，不依赖 DSH 的背景插槽。设置入口在「外观」。

## 容器与材质边界

| 区域 | 处理 | 原因 |
| --- | --- | --- |
| 主框架、聊天布局外壳 | 仅这两个结构容器移除实色填充 | 让根级媒体层可见；不批量重置子节点 |
| 左侧导航 | 带 76% 主题底色的 24px 毛玻璃 | 保持导航稳定，同时体现背景色彩 |
| 顶部栏 | 86% 主题底色、20px 毛玻璃 | 按钮和标题保持可读；侧栏内标题继承已有导航材质 |
| 聊天阅读区，含空会话 | 80% 主题底色、10px 毛玻璃 | 整个区域只做一次柔化，不逐条消息堆叠滤镜 |
| 输入卡片 | 90% 主题底色、28px 毛玻璃和原有边界 | 建立比阅读区更稳定的输入表面 |
| 吸顶用户消息 | 保留实色底层 | 遮住从下方滚过的正文，避免文字叠影 |
| 代码、终端、工作区内容、工具卡片 | 保留组件现有表面 | 不改变专业内容的对比度和语义颜色 |
| 菜单、弹窗、设置、审批 | 保留原有表面 | 全局主题 token 不被改写，portal 也不受透明化规则影响 |
| Quick Ask、桌面宠物独立窗口 | 不接入此背景 | 背景仅属于主界面 |

「增强可读性」将阅读区、导航、输入卡片底色提高到 93%、91%、97%。所有材质随现有深浅主题变化。浏览器不支持 backdrop-filter 或系统要求减少透明效果时，主要阅读表面回退为不透明。

可设置：启用、图片/视频、暂停封面、播放/暂停、铺满/完整显示、压暗 0–65%、背景模糊 0–20px、均衡/增强可读性。视频循环静音播放；隐藏窗口或 `prefers-reduced-motion` 生效时暂停。封面可选，无封面时保留视频帧。解码失败时恢复默认表面并显示可关闭提示，不把失败背景继续透到正文下方。

## Agent 工作流

1. 用户给出原图并要求生成动态背景。Agent 使用现有 `media_describe` 获取已配置模型的能力及参数协议。
2. 用支持图片输入的模型执行 `media_generate`（例如 MiniMax 的首帧视频协议）；按现有媒体任务机制等待完成并取得已保存的本地视频。生成费用仍走媒体插件现有策略。
3. `background_import({filePath: "…/generated.mp4"})` 将视频复制到持久化素材库，返回 `id`。可再导入原图用于 `posterId`。
4. `background_get()` 读取当前完整配置及 `revision`。
5. `background_configure({configJson: JSON.stringify({...config, enabled:true, assetId: video.id, posterId: image.id, motion:"play"}), revision})` 应用背景。

生成、保存、应用是三个独立状态。生成任务仅提交或仍在运行时不可宣称背景已完成。上游链接可能过期，因此背景仅使用已导入的本地资产，不把签名 URL 或临时文件路径存成最终背景。

设置 UI 和 Agent 共用 `BackgroundStore` / `amibaBackground` 服务。配置与资产位于当前 DSH home 下的 `amiba/backgrounds`；配置使用原子替换和 revision 校验，Agent 的旧读取不会覆盖同一宿主上较新的 UI 写入。窗口共享一次每 3 秒的可见状态轮询；重新可见时立即读取。资产按内容哈希去重，选择新背景不会删除旧资产。

支持 PNG、JPEG、WebP、MP4、WebM，单个文件上限 64 MiB。文件会校验媒体签名；SVG/HTML 不作为背景执行。Web 上传和下载均走现有 Typert 通道的 256 KiB 分块，客户端从 Blob 播放，兼容 Electron 的 file:// 入口。素材完整导入之后才允许激活。

## 验证与边界

- 宿主测试覆盖生成产物复制、源文件删除后读取、重启恢复、并发 revision 冲突、上传顺序/大小、非法媒体与路径、配置校验。
- 真实 Cordis Context 测试覆盖 Agent 工具注册/卸载、导入与配置，以及远端服务读取同一状态。
- React 测试覆盖加载完成前保持默认表面、解码失败回退、隐藏/减少动态效果暂停、关闭时释放 Blob。
- `node apps/desktop/scripts/smoke-background.mjs` 使用真实 Chromium 视频解码、实际背景组件/设置组件/输入器和明确标记的布局夹具，验证素材上传到宿主后应用、材质、深浅色、暂停、刷新恢复与关闭。截图默认输出 `/tmp/amiba-background-evidence`。这是组件集成夹具，不等同于完整发行版主界面验收。
- 尚未调用付费图生视频模型验证真实生成，也未进行 Windows/发行包验收。模型能力、凭据和余额由现有媒体插件提供，本功能不新增视频生成服务。
