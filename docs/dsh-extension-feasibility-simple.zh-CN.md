# 扩展适配判断：简明版

评估范围：初次审计的 64 个官方扩展入口，另列服务层的明确限制。实际运行基线为 DSH 0.1.1-rc.2；新版对照固定在 c291e796，并非声称覆盖此后所有版本。

**38 项已有接入基础；6 项需要进一步验证适配；20 项只能有条件适配。没有证据证明其中某一整类普通扩展永久无法接入。**

这些数量统计的是扩展入口，不是插件数量，也不是完整兼容率。入口已接入不代表使用它的所有第三方插件均已通过验证。

## 4. 有确切原因的操作限制

| 具体操作 | 判断 | 确切原因 | 可行替代 |
| --- | --- | --- | --- |
| 一次性子会话继续发送或停止 | 当前 rc.2 无法通过公共接口支持 | 公共 Session.prompt 和 Session.cancel 明确拒绝 one-shot 会话 | 读取历史；要改变此能力，需要上游契约支持 |
| 可续聊子会话向模型发送图片 | 当前 rc.2 无法完整支持 | 公共 Session.prompt 明确拒绝子会话 image 输入 | 支持文本续聊；图片命令已另行验证，不等于模型图片输入 |
| 冷重启后继续嵌套子会话 | 有条件支持 | 必须先驻留直接父 Agent；冷父本身是子会话时，没有公开的无消息恢复操作 | 普通根父可以恢复；嵌套冷父需先实际运行，再重试原草稿 |
| 任意第三方插件直接操作官方私有 DOM | 无法保证通用兼容 | Amiba 的 DOM、组件结构和生命周期不同，且私有接口没有稳定契约 | 插件改用公共接口，或逐个做专用适配 |
| 纯浏览器调用 Electron 专属系统能力 | 无法原样支持 | 浏览器不存在 Electron 主进程及其系统 API | 使用桌面宿主、服务端代理或降低功能范围 |
| 任意 Markdown 变换后的精确源位置映射 | 无法保证通用兼容 | 变换如果丢弃源位置和对应关系，适配层无法可靠还原 | 要求变换保留源位置，或由插件提供映射 |

## 5. 仍可做，但尚未完成的重点

| 能力 | 结论 |
| --- | --- |
| 官方详情面板开关 | 已补齐 openDetails/closeDetails 的实际处理，保留各会话原文件和面板状态；新版右侧栏服务仍需另外接入。 |
| 官方完整输入与队列 | 可继续适配。离屏文本和命令已验证；忙碌会话的离屏排队也已通过桌面验证；停止状态已能跨会话切换保留；后台自动出队、前后台交接和失败保留已通过真实 Host 回归；后台重定向连续派发及目标目录恢复也已实测；双队列顺序、前台目标交接、跨窗口、跨重启协调和 Host inbox 对齐仍未完成。 |
| 引用、粘贴和图片生命周期 | 可继续适配。跨挂载引用身份、部分粘贴语义、跨窗口附件所有权仍需补齐。 |
| Host 队列与原生队列对齐 | 当前 rc.2 Host 队列编辑仅接受文本，且 updateQueue 拒绝子会话目标；原生已有图片编辑和子会话队列。需要专用适配，不能直接替换而丢失原功能。 |
| 新版审批、图片、右侧栏和模型服务 | 需要迁移真实服务和生命周期；不能仅注册插槽就宣布支持。 |
| 独立 Web 和远程部署 | 需要独立验证资源、下载、目录和连接行为；桌面通过不能推断 Web 也通过。 |
| 流式重连与历史附件回收 | 可继续适配；须保证不丢内容、不误删历史使用的文件。 |
