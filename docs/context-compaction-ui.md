# 对话流中的上下文压缩状态

Amiba UI Shell 使用共享聊天组件展示 DSH 压缩生命周期，不需要额外插件，也不改变后端压缩策略。

- `compaction/start` 显示“正在压缩上下文…”。
- `compaction/summary` 更新摘要和被替换历史的条数、token 数；摘要生成不等于压缩成功。
- `compaction/end` 无错误时显示“上下文已压缩”，携带错误时显示“上下文压缩失败”。摘要和错误详情默认折叠。
- 同一会话内按 `compactionId` 更新原位置的记录。重复开始事件不会重新启动已结束的状态；连续多次压缩分别保留。
- 轮次结束仍未收到压缩结束事件时标记为中断。历史只有开始事件、没有可确认的实时状态时显示“压缩状态待确认”，不伪装成仍在运行或已完成。

事件桥和历史投影共用 `packages/app-runtime/src/dsh-client/compaction.ts`。实时事件通过 Chat Engine、ChatSurface 和流缓冲器进入 assistant timeline；历史投影恢复相同的记录。压缩失败不修改任务的错误状态，检查点的模型输入消息也不会变成用户气泡。

`packages/ui/src/chat/bubble/CompactionRow.tsx` 负责展示。包含压缩的消息保留按时间排列的文本、执行折叠行和压缩行，完成后压缩记录仍直接可见。压缩中隐藏重复的通用运行指示；已有 SurfaceActivity 阶段不变。

验证覆盖：生命周期实时/历史一致性、原位更新和重复事件、失败与中断、无开始事件的局部历史、宿主任务和本地任务事件、会话快照、流缓冲不可变更新、对话流排序与摘要展开。Electron 组件渲染检查使用合成事件数据验证中英文配置中的中文展示、浅色和深色窄窗口；未依赖真实模型触发压缩。
