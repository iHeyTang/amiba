# DSH 扩展兼容收尾清单

目标保持不变：以 main 为基线接入所有可兼容能力，保留 Amiba 已有能力和样式。范围仍为原审计的 64 个入口、相关服务语义，运行基线 DSH 0.1.1-rc.2，新版对照固定 c291e796。44 个入口有接入基础、20 个替换类入口有条件适配，不是完成率。

## 已有成果

设置和插件配置、附加输入入口、工具/审批详情、导航和祖先关系、右侧工作区、文本/代码/图片/HTML/PDF 预览、会话授权文件服务、消息/工具/轨迹图片基础链路、后台输入和部分队列、引用剪贴板与会话历史均已有实现及不同范围的桌面验证。每项实际覆盖范围仍以 [64 项详细表](dsh-extension-adaptation-assessment.zh-CN.md) 为准；不能据此推断全部插件、平台、编码变体均完成。

## 已确认的上游限制

- rc.2 一次性子会话不允许通过公共接口继续发送或停止。
- rc.2 可续聊子会话不支持向模型发送图片；文本与图片命令不是同一能力。
- 冷嵌套子会话需直接父 Agent 驻留；缺少恢复冷子父会话的公共无消息操作。
- rc.2 Host 队列编辑仅支持文本，拒绝子会话目标；不能直接替换原生图片/子会话队列。
- 私有 DOM 依赖、纯浏览器的 Electron API、已丢失的 Markdown 源位置映射不能保证通用兼容；可行专用适配仍按具体组件核对。

## 执行约束

按上述功能组集中实现和回归，不将每个边界用例拆成独立阶段。没有生产代码变更或新失败依据时，不重复完整构建和桌面回归。必要失败应修复并记录；新发现的问题归入原功能组，不能据此不断扩张目标。保留原始 64 项范围，不能把尚未验证项改称上游不支持来提前收尾。

## 不计入兼容缺口的额外增强

重启后恢复整个撤销/重做栈：已核对 rc.2 与 c291e796，官方新建空历史，只镜像和恢复草稿。该能力不是已审计官方契约中的支持项，不再把它作为无限延伸的收尾条件。草稿、队列和附件的持久化要求不受此纠正影响。
