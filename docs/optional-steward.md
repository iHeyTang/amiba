# 大管家改为独立可选项目

大管家源码和测试已迁出默认插件集合，独立项目位于同级 `amiba-steward/`（`hermes-x/amiba-steward`）。
Amiba core 不再声明或加载 `@amiba/dsh-plugin-steward`，新安装不包含管家导航、工具和后台服务。

本次不删除 `amiba-steward` 数据目录，不清理历史管家会话；手动安装的外部版本也不在卸载范围内。
开发运行时应重新生成 bundle 并重启，已加载进程不会因删除源文件自动卸载。

备用项目包含独立构建配置、单元测试、开发依赖锁和本地打包命令。
其 UI、会话生命周期依赖仍是 Amiba 宿主接口，安装兼容版本后可以单独恢复使用。
历史设计文档中的旧源码路径指向迁出前版本，查阅时使用 Git 历史或独立项目。
